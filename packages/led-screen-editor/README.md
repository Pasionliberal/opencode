# LED Screen Editor

Una app moderna para diseñar y animar pantallas LED. Dibuja píxeles, crea animaciones y guarda tu trabajo.

## Características

- 📐 **Editor de píxeles** - Grilla de 32x18 con todas las herramientas
- 🎨 **Colores RGB** - 12 colores predefinidos + selector personalizado
- ✏️ **Múltiples herramientas** - Pincel, borrador, líneas, formas
- 🎬 **Animaciones** - Crea fotogramas y reproduce
- 📱 **Responsive** - Optimizado para celular, tablet y desktop
- 💾 **Exportar** - Descarga como imagen o JSON

## Secciones

### Editor
Interfaz principal con:
- Toolbar con todas las herramientas
- Canvas interactivo de 32x18 píxeles
- Control de animaciones
- Descarga de imagen

### Dibujo Libre
Espacio sin restricciones para:
- Dibujar con pincel personalizable
- Guardar fotogramas
- Reproducir animaciones
- Exportar en JSON

## Instalación

```bash
# Instalar dependencias
npm install

# Ejecutar en desarrollo
npm run dev

# Build para producción
npm run build

# Preview
npm run preview
```

## Tecnología

- React 18
- TypeScript
- Vite
- HTML5 Canvas
- CSS3
